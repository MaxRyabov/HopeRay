## ADDED Requirements

### Requirement: Нет встроенных источников ключей
Приложение MUST NOT предлагать получить ключ или профиль из встроенного источника: списка бесплатных конфигов, каталога серверов, пробного ключа. Приложение MUST NOT запрашивать список бесплатных конфигов по сети.

#### Scenario: Окно добавления профиля без «Free»
- **WHEN** пользователь открывает окно добавления профиля
- **THEN** в окне нет переключателя «Free» и списка бесплатных профилей
- **AND** доступны только способы «Буфер обмена», «Вручную» и, на мобильных платформах, «QR-код»

#### Scenario: Нет запроса к списку бесплатных конфигов
- **WHEN** пользователь открывает окно добавления профиля и закрывает его
- **THEN** приложение не выполняет HTTP-запросов к `raw.githubusercontent.com/hiddify/hiddify-app/.../free_configs`

### Requirement: Нет внешних инструкций по получению сервера
Приложение MUST NOT ссылаться на внешние инструкции по созданию или получению сервера. Это касается и `hiddify.com/manager/`.

#### Scenario: Окно добавления профиля без «Help»
- **WHEN** пользователь открывает окно добавления профиля
- **THEN** в окне нет чипа «Help»

#### Scenario: Подключение без профиля
- **WHEN** у пользователя нет активного профиля и он нажимает кнопку подключения
- **THEN** показывается диалог, который просит добавить выданный ключ доступа
- **AND** в диалоге нет кнопки «Show me how» и ссылок на внешние сайты
- **AND** текст диалога не упоминает бесплатные серверы и создание своего сервера

### Requirement: Путь к добавлению ключа из диалога
Диалог «нет профиля» MUST вести пользователя к добавлению ключа.

#### Scenario: Добавление ключа из диалога
- **WHEN** пользователь закрывает диалог «нет профиля», открытый кнопкой подключения
- **THEN** открывается окно добавления профиля
