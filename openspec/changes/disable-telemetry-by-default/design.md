## Context

- `AnalyticsController.build()` возвращает `getBool(enable_analytics) ?? true`. `bootstrap.dart` вызывает `enableAnalytics()` (инициализацию Sentry), если значение `true`. DSN передаётся через `--dart-define sentry_dsn`. В TestFlight DSN пустой, но на остальных платформах CI передаёт `secrets.SENTRY_DSN`.
- `IntroPage.autoSelectRegion` сначала определяет регион по часовому поясу. При исключении он запрашивает `https://api.ip.sb/geoip/`.
- `PerAppProxyNotifier.shareOnGithub` открывает в браузере issue в `hiddify/Android-GFW-Apps` со списком пакетов пользователя.

## Goals / Non-Goals

**Goals:**
- Без явного согласия данные не уходят третьим сторонам.
- Поведение соответствует декларации App Privacy «Data Not Collected» при выключенной аналитике.

**Non-Goals:**
- Удаление Sentry из зависимостей: пользователь может включить аналитику сам.
- Проверки IP на главном экране (`proxy_repository.dart`: ipwho.is, ipinfo.io и другие). Они показывают пользователю его внешний IP после подключения и идут через туннель. Это отдельное решение, в этот change оно не входит.
- Загрузка списка приложений для автовыбора per-app proxy (`auto_selection_repository.dart`) — это функциональность, а не телеметрия.
- Privacy manifest iOS: в change `ios-surface-hardening`.

## Decisions

- **Менять только значение по умолчанию (`?? false`), без миграции.** Явный выбор пользователя сохраняется. Пользователи без сохранённого значения переходят на «выключено». Это и нужно: они согласия не давали.
- **Удалить запасной geo-IP запрос, а не заменить другим сервисом.** Регион по часовому поясу срабатывает почти всегда. При неудаче остаётся `Region.other` и пользователь может выбрать регион на том же экране интро.
- **Удалить `shareOnGithub` целиком**, вместе с кнопкой на `per_app_proxy_page.dart` и строками перевода.

## Risks / Trade-offs

- [Меньше отчётов о сбоях] → отчёты приходят от тех, кто включил аналитику. Диагностика по логам (`LogsPage`) остаётся.
- [Регион не определится на устройствах с нестандартным часовым поясом] → пользователь выбирает регион вручную в интро.
