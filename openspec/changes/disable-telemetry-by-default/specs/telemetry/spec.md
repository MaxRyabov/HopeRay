## ADDED Requirements

### Requirement: Аналитика выключена по умолчанию
Если пользователь явно не включил аналитику, она MUST быть выключена. Без явного включения приложение MUST NOT инициализировать Sentry и отправлять отчёты о сбоях.

#### Scenario: Чистая установка
- **WHEN** приложение запускается впервые и настройки `enable_analytics` нет
- **THEN** `analyticsControllerProvider` возвращает `false`
- **AND** Sentry не инициализируется при запуске

#### Scenario: Пользователь включил аналитику
- **WHEN** пользователь включает аналитику в интро или в настройках
- **THEN** сохраняется `enable_analytics = true`, и при следующих запусках аналитика включена

#### Scenario: Пользователь ранее явно выключил аналитику
- **WHEN** сохранено `enable_analytics = false`
- **THEN** аналитика выключена

### Requirement: Регион без сетевых запросов
Интро MUST определять регион без сетевых запросов к сторонним сервисам геолокации.

#### Scenario: Часовой пояс не распознан
- **WHEN** `RegionDetector.detect()` бросает исключение
- **THEN** приложение не обращается к `api.ip.sb` и другим сервисам геолокации
- **AND** регион остаётся значением по умолчанию

### Requirement: Нет публикации данных пользователя во внешние репозитории
Приложение MUST NOT предлагать публиковать данные пользователя (список установленных приложений и другие) в публичные репозитории и трекеры задач.

#### Scenario: Экран per-app proxy
- **WHEN** пользователь открывает экран per-app proxy на Android
- **THEN** на экране нет действия «Поделиться на GitHub», и приложение не открывает `github.com/hiddify/Android-GFW-Apps/issues/new`
